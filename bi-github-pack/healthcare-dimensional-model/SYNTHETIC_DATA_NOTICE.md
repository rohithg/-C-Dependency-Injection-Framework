# SYNTHETIC DATA NOTICE

Every dataset in this repository is **fabricated for portfolio demonstration**.

- No real patients, members, providers, or claims
- No real PHI / ePHI
- Identifiers use `SYN-`, `DEMO-`, and `EMPI-SYN-` prefixes
- Provider NPIs are placeholder 10-digit strings, not NPPES records

If you fork this project, keep development data synthetic.

# C# Dependency Injection Framework

Custom DI container demonstrating C# advanced features and SOLID principles.

## Features

- Generic type constraints
- Reflection API
- LINQ queries
- Service lifetimes
- Constructor injection
- Interface-based design

## Also in this repo

- **[Live Power BI + Snowflake agents](bi-github-pack/powerbi-snowflake-live-agents/)** — Cursor agents that generate live DirectQuery drill-down Power BI dashboards from Snowflake views (PBIP / TMDL / PBIR).

## Compilation

```bash
csc /out:DIFramework.exe DIContainer.cs
```

## Running

```bash
./DIFramework.exe
```
